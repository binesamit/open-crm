# המדריך למשתמשי Bines OS

גרסה באנגלית: [README.md](README.md)

המדריך הזה נכתב בשביל מי שעובד ב-Bines OS ביום-יום: מנהלים, אנשי צוות וכל מי שהוזמן לבורד. כל עמוד מסביר תחום אחד
במערכת, עם משימות קצרות צעד אחר צעד. לא צריך שום ידע טכני.

מתקינים את המערכת על שרת משלכם? ראו את [מדריך ההתקנה והרישוי](../GUIDE.he.md). בונים משהו על בסיס Bines OS? ראו את
[תיעוד ה-API](../06-API.md) ואת [מדריך התוספות](../EXTENSIONS-GUIDE.he.md).

## מתחילים כאן

- [תחילת עבודה](getting-started.he.md): כניסה למערכת, חשבונות, מרחבי עבודה, תיקיות, בורדים, דף הבית ועבודה מהטלפון.
- [בורדים, קבוצות ופריטים](boards-groups-items.he.md): עבודה עם קבוצות, פריטים ותתי-פריטים, העברה ושכפול, עריכה של
  הרבה פריטים בבת אחת, ביטול פעולה וסל המחזור.
- [עמודות](columns.he.md): כל סוגי העמודות במילים פשוטות, נוסחאות, חיבור בורדים, עמודות מראה, כפתורים ושם מחושב.
- [תצוגות](views.he.md): טבלה, קנבן, גאנט, ציר זמן, לוח שנה, מפה, קבצים, גרף, טופס ועוד.
- [חיפוש, סינון, מיון וקיבוץ](search-filter-sort-group.he.md): למצוא דברים מהר ולקבוע מה התצוגה מראה.
