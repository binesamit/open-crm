מי שעובד במערכת כל היום יודע כמה זמן נחסך כשהידיים נשארות על המקלדת. Bines OS תומכת בשורה של קיצורי מקלדת: לביטול פעולה שבוצעה בטעות, לחיפוש מהיר, לתנועה בין תאים בטבלה כמו בגיליון אלקטרוני, ולעבודה עם תפריטים בלי עכבר. במאמר הזה תמצאו את הרשימה המלאה, מסודרת לפי ההקשר שבו כל קיצור פועל.

## מה תלמדו

- איך פותחים את רשימת הקיצורים מתוך המערכת
- קיצורים כלליים שפועלים בכל מקום
- קיצורים לעבודה בבורד ובטבלה
- קיצורים לעבודה עם תפריטים

## פתיחת רשימת הקיצורים

בכל מסך, הקישו **Shift+?** (כשהסמן לא נמצא בתוך שדה טקסט). ייפתח החלון **קיצורי מקלדת** עם כל הקיצורים, מחולקים לשלושה חלקים: **כללי**, **בבורד** ו**תפריטים**. סגרו אותו ב-Esc.

![חלון קיצורי המקלדת עם שלושת החלקים: כללי, בבורד ותפריטים](images/keyboard-shortcuts-1.webp)

> **טיפ:** במחשבי Mac השתמשו ב-⌘ (Cmd) בכל מקום שכתוב Ctrl. הקיצורים עם אותיות פועלים בכל פריסת מקלדת — גם כשהמקלדת על עברית.

## קיצורים כלליים

| קיצור | פעולה |
| --- | --- |
| Shift+? | **רשימת הקיצורים** |
| Ctrl+Z | **ביטול הפעולה האחרונה (עד דקה)** |
| Ctrl+Shift+Z (או Ctrl+Y) | **ביצוע שוב של מה שבוטל** |
| Ctrl+B | **חיפוש בכל מקום** |
| Esc | **סגירת חלון / תפריט** |

> **שימו לב:** ביטול עם Ctrl+Z זמין לפעולה האחרונה שביצעתם, במשך דקה מרגע הביצוע. לשחזור דברים ישנים יותר השתמשו ביומן הפעילות של הבורד, בסל המחזור או בארכיון.

## קיצורים בבורד

### כללי בבורד

| קיצור | פעולה |
| --- | --- |
| Ctrl+F | **חיפוש בבורד** |
| Ctrl+G | **כיווץ / הרחבה של כל הקבוצות** |
| Ctrl+Shift+L | **יומן הפעילות של הבורד** |

### בחירת פריטים

| קיצור | פעולה |
| --- | --- |
| Ctrl+A | **בחירת כל הפריטים בתצוגה** |
| Shift+לחיצה | **בחירת טווח (בתיבת הסימון)** — לחצו על תיבת הסימון של פריט אחד, ואז Shift+לחיצה על אחר |
| Delete | **מחיקת הפריטים שנבחרו** |
| Esc | **ביטול הבחירה** |

### תנועה ועריכה בטבלה

הטבלה מתנהגת כמו גיליון אלקטרוני: לחצו על תא אחד, ומשם אפשר לעבוד מהמקלדת.

| קיצור | פעולה |
| --- | --- |
| חיצים ↑ ↓ ← → | **מעבר בין תאים** |
| Tab / Shift+Tab | **התא הבא / הקודם** |
| Enter | **עריכת התא** |
| Shift+חיצים | **בחירת טווח תאים** |
| Ctrl+C / X / V | **העתקה / גזירה / הדבקה של תאים** |
| Delete | **ניקוי התא (או הטווח)** |

> **טיפ:** אפשר להעתיק טווח תאים מהמערכת ולהדביק אותו באקסל, ולהפך — להעתיק נתונים מגיליון ולהדביק אותם ישירות לטבלה.

## קיצורים בתפריטים

| קיצור | פעולה |
| --- | --- |
| Shift+F10 | **תפריט הפעולות של מה שבפוקוס** — כמו לחיצה ימנית |
| ↑ ↓ | **מעבר בין פריטי תפריט** |
| Enter | **בחירה בפריט תפריט** |
| Esc | סגירת התפריט |

כך אפשר, למשל, לעבור עם Tab לשורה בסרגל הצד, להקיש Shift+F10 כדי לפתוח את התפריט שלה, לבחור פעולה בחיצים ולאשר ב-Enter — בלי לגעת בעכבר.

## שאלות נפוצות

**הקשתי Shift+? ולא קרה כלום.**\
ייתכן שהסמן נמצא בתוך שדה טקסט, ואז המקש פשוט מקליד את התו. לחצו מחוץ לשדה (או הקישו Esc) ונסו שוב.

**Ctrl+F פותח את החיפוש של הדפדפן ולא של הבורד.**\
הקיצור פועל רק כשבורד פתוח במסך. במסכים אחרים הדפדפן מטפל בו כרגיל.

**האם אפשר להגדיר קיצורים משלי?**\
כרגע לא. הרשימה בחלון **קיצורי מקלדת** היא הרשימה המלאה של הקיצורים הזמינים.

- ביטול פעולות ויומן הפעילות
