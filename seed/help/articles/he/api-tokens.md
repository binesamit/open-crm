טוקן API הוא "מפתח" שמאפשר לכלי חיצוני — Make, n8n, סקריפט שכתבתם או כלי AI — לעבוד עם החשבון שלכם דרך ה-API: לקרוא לוחות ופריטים, ליצור פריטים, לכתוב עדכונים ועוד. הטוקן פועל בשמכם ובהרשאות שלכם, ואף פעם לא יותר מהן. אתם בוחרים בדיוק מה הוא רשאי לעשות, על אילו לוחות ולכמה זמן — ויכולים להשבית אותו בכל רגע.

## מה תלמדו

- איפה מנהלים טוקנים, ומה ההבדל בין טוקן אישי לטוקן שירות
- איך יוצרים טוקן ומגבילים אותו
- איך משתמשים בטוקן בבקשות API
- איך מגבילים קצב שימוש ומשביתים טוקן

## איפה מנהלים טוקנים

- **הטוקנים שלכם:** בתפריט המשתמש בסרגל העליון ← **הפרופיל שלי** ← לשונית **טוקני API**.
- **מנהלי החשבון:** **ניהול החשבון** ← **חיבורים**. שם מוצגים, עם הסימון **הצג את הטוקנים של כל החברים**, הטוקנים של כל החשבון, ושם גם יוצרים טוקני שירות.

> **שימו לב:** צופים ואורחים אינם יכולים ליצור טוקנים, ולכן לא תופיע אצלם הלשונית.

| סוג | מי יוצר | בשם מי הוא פועל |
| --- | --- | --- |
| **טוקן אישי** | כל חבר צוות ומנהל | בשמכם, עם ההרשאות שלכם |
| **טוקן שירות** | מנהלי החשבון בלבד | נוצר משתמש מיוחד "שירות: \<שם\>", עם תפקיד משלו בחשבון. הפעולות שלו נרשמות ביומן בשמו, לא בשם אדם |

טוקן שירות מתאים לחיבורים קבועים של הארגון (למשל אינטגרציה של המערכת עם אתר), כדי שהחיבור לא יפסיק לעבוד כשעובד עוזב.

## יצירת טוקן

1. לחצו על **טוקן חדש** (או, למנהלים, **טוקן שירות חדש**).
2. ב**שם** תנו שם שיזכיר לכם למה הטוקן — למשל "Make — לידים מהאתר".
3. בטוקן שירות, בחרו **תפקיד השירות בחשבון**: **חבר צוות** או **מנהל**.
4. תחת **מה הטוקן יכול לעשות**, סמנו רק את ההרשאות הדרושות (ראו טבלה).
5. תחת **לאילו לוחות**, השאירו **כל הלוחות שלי** או בטלו את הסימון ובחרו לוחות מסוימים.
6. בחרו **תוקף**: 30 ימים, 90 ימים, שנה או **ללא תפוגה**.
7. אפשר לקבוע **מגבלות שימוש** — בקשות לדקה ובקשות ליום. שדה ריק = ברירת המחדל של החשבון.
8. לחצו **טוקן חדש**. בחלון **הטוקן נוצר** לחצו **העתקה**.

![חלון יצירת טוקן עם בחירת הרשאות, לוחות ותוקף](images/api-tokens-1.webp)

> **שימו לב:** העתיקו את הטוקן מיד — הוא לא יוצג שוב. מי שמחזיק בו פועל בשמכם, אז שמרו אותו במקום מאובטח ואל תשתפו אותו.

### ההרשאות שאפשר לתת

| הרשאה | מה היא מאפשרת |
| --- | --- |
| **קריאת לוחות ופריטים** | לקרוא לוחות, עמודות, פריטים וערכים |
| **שינוי מבנה לוחות** | ליצור ולשנות לוחות, קבוצות, עמודות ותצוגות |
| **יצירה ועריכה של פריטים** | ליצור, לעדכן ולמחוק פריטים וסאב-אייטמים |
| **קריאת עדכונים** / **כתיבת עדכונים** | לקרוא ולכתוב עדכונים בפריטים |
| **קריאת משתמשים** / **ניהול משתמשים (מנהל)** / **ניהול צוותים** | אנשי החשבון וצוותים |
| **קריאת אוטומציות** / **ניהול אוטומציות** | לצפות באוטומציות או ליצור ולשנות אותן |
| **צפייה בסוכני AI ובהרצות שלהם** / **הפעלת סוכני AI** / **ניהול סוכני AI** | עבודה עם סוכנים |
| **Webhooks** | לרשום webhooks לבורדים |
| **קריאת התראות** / **סימון התראות** | התראות של המשתמש |
| **חיפוש** | חיפוש בכל החשבון |
| **הכל (מנהל)** | כל הפעולות, למנהלים בלבד |
| **חשיפת סודות** | קריאת ערכים בעמודות סוד — למנהלים בלבד, ולא נכלל ב"הכל" |

## שימוש בטוקן

בכל בקשה שולחים את הכותרת:

`Authorization: Bearer <הטוקן>`

כתובת הבסיס של ה-API היא כתובת המערכת שלכם עם `/api/v1`. למשל, ליצירת פריט שולחים POST לכתובת `/api/v1/boards/<מזהה הלוח>/items` עם גוף JSON.

### מ-Make או מ-n8n

1. ב-Make השתמשו במודול **HTTP → Make a request**; ב-n8n — בצומת **HTTP Request**.
2. הוסיפו את כותרת ה-Authorization עם הטוקן.
3. הגדירו את גוף הבקשה כ-JSON.

בתחתית מסך הטוקנים תמצאו את הכרטיס **חיבור מ-Make / n8n** עם דוגמה מוכנה, ואת הקישור **כל הנקודות של ה-API (תיעוד)** — תיעוד מלא באנגלית, עם דוגמאות לכל פעולה, מגבלות קצב והסבר על שגיאות.

> **טיפ:** כדי לקבל אירועים מהבורד (במקום לבדוק שוב ושוב), השתמשו ב-webhooks. ראו "Webhooks נכנסים ויוצאים".

## מגבלות קצב

לכל טוקן יש מגבלת בקשות לדקה וליום. בשורת הטוקן מוצג הסיכום — למשל "600 לדקה · 10,000 ליום". כדי לשנות, לחצו **מגבלות** בשורה. מגבלה גבוהה מברירת המחדל של החשבון — רק מנהל חשבון יכול לקבוע. בקשה שחורגת מהמגבלה מקבלת תשובת "יותר מדי בקשות", עם זמן המתנה מומלץ.

![רשימת טוקנים עם הרשאות, שימוש אחרון, תוקף ומגבלות](images/api-tokens-2.webp)

## השבתת טוקן

1. בשורת הטוקן לחצו **השבתה**.
2. אשרו: **להשבית את הטוקן? חיבורים שמשתמשים בו יפסיקו לעבוד.**

בכל שורה מוצגים גם **שימוש אחרון** ותאריך התפוגה, כדי שתוכלו לזהות טוקנים שכבר לא בשימוש ולהשבית אותם.

## שאלות נפוצות

**הטוקן שלי קיבל שגיאת הרשאה. למה?**\
הטוקן מקבל את החיתוך בין ההרשאות שסימנתם לבין ההרשאות שלכם בפועל. אם אין לכם גישה ללוח, גם לטוקן אין. ודאו גם שהלוח נמצא ברשימת הלוחות של הטוקן.

**איפה רואים אפליקציות AI שחוברו לחשבון?**\
באותו מסך, באזור **אפליקציות AI מחוברות**. ראו "חיבור עוזרי AI חיצוניים (MCP)".
