בונה האוטומציות מאפשר לכם להרכיב כל כלל שתרצו, כמשפט שנקרא בעברית פשוטה: **מתי** (טריגר), **ורק אם** (תנאים), **אז** (פעולות). כל חלק שצריך להשלים מופיע כ"צ'יפ" — לוחצים עליו ובוחרים ערך מתוך רשימה. אין צורך לכתוב קוד ואין צורך לזכור שמות של עמודות.

## מה תלמדו

- איך פותחים את הבונה ומשלימים משפט
- אילו טריגרים ופעולות זמינים, ומה כל אחד עושה
- איך מוסיפים תנאים, כולל "או", קבוצות תנאים ושלילה
- איך משתמשים במשתנים כמו שם הפריט וקישור אליו
- איך עובדים עם סאב-אייטמים ופריט האב

## פתיחת הבונה

1. בכותרת הבורד, לחצו על **אוטומציות**.
2. עברו ללשונית **יצירה** ולחצו על **בנה אוטומציה מותאמת** — או בחרו מתכון מוכן כנקודת התחלה.
3. כדי לערוך אוטומציה קיימת, לחצו בלשונית **ניהול** על **עריכה** בשורה שלה.

החלון נקרא **אוטומציה חדשה** (או **עריכת אוטומציה**) ובנוי משלוש שורות: **מתי**, **ורק אם**, **אז**.

![בונה האוטומציות עם טריגר של שינוי סטטוס, תנאי ושתי פעולות](images/automation-builder-1.webp)

## שלב 1: בחירת הטריגר

לחצו על הצ'יפ שליד **מתי** ובחרו טריגר מהתפריט. הטריגרים מקובצים לפי נושא:

| קבוצה | טריגר | איך הוא נקרא במשפט |
| --- | --- | --- |
| שינוי סטטוס | כשסטטוס משתנה | כש{עמודה} משתנה ל{תווית} |
| שינוי עמודה | כשעמודה משתנה | כש{עמודה} משתנה |
| שינוי עמודה | כשלוחצים על כפתור | כשלוחצים על {עמודה} |
| שינוי עמודה | כשמסמנים תיבה | כש{עמודה} מסומן / לא מסומן |
| שינוי עמודה | כשמשבצים אדם | כש{מישהו} משובץ ב{עמודה} |
| שינוי עמודה | כשמספר חוצה סף | כש{עמודה} גדול מ- / קטן מ- {ערך} |
| יצירה ותזוזה של פריטים | כשנוצר פריט | כשנוצר פריט |
| יצירה ותזוזה של פריטים | כשנוצר פריט בקבוצה | כשנוצר פריט בקבוצה {קבוצה} |
| יצירה ותזוזה של פריטים | כשפריט עובר קבוצה | כשפריט מועבר לקבוצה {קבוצה} |
| יצירה ותזוזה של פריטים | כשנכתב עדכון | כשנכתב עדכון (אפשר: שמכיל טקסט מסוים) |
| יצירה ותזוזה של פריטים | כשפריט עובר לארכיון / נמחק / משוחזר | כשפריט מועבר לארכיון, כשפריט נמחק, כשפריט משוחזר |
| סאב-אייטמים | כשנוצר סאב-אייטם | כשנוצר סאב-אייטם |
| סאב-אייטמים | כשסטטוס של סאב-אייטם משתנה | כש{עמודה} של סאב-אייטם משתנה ל{תווית} |
| סאב-אייטמים | כשעמודה של סאב-אייטם משתנה | כש{עמודה} של סאב-אייטם משתנה |
| תאריכים וזמן | כשתאריך מגיע | כשמגיע התאריך ב{עמודה} ביום עצמו / N ימים לפניו או אחריו, בשעה {שעה} |
| תאריכים וזמן | N ימים לפני תאריך | {N} ימים לפני התאריך ב{עמודה}, בשעה {שעה} |
| תאריכים וזמן | כל יום / שבוע / חודש | כל שעה / יום / שבוע ביום… / חודש ב-… לחודש, בשעה {שעה} — לכל פריט בבורד |
| חוצה לוחות | כשכל המקושרים הושלמו | כשכל הפריטים המקושרים ב{עמודת חיבור} הושלמו |
| Webhooks | Webhook נכנס | כשמתקבל webhook ממערכת חיצונית |
| Webhooks | זרימה חיצונית נכשלה / חזרה לעבוד | כשזרימה נכשלת ב{חיבור}: {זרימה} |

> **טיפ:** אם הותקנו בחשבון תוספות שמספקות טריגרים, הן מופיעות בתחתית התפריט תחת **מתוספות**.

כשבוחרים עמודה, הרשימה מציגה רק עמודות מהסוג המתאים (למשל רק עמודות סטטוס בטריגר של סטטוס). בבורד עם סאב-אייטמים הרשימה מחולקת ל**עמודות הפריט** ו**עמודות סאב-אייטם** — ובחירה בעמודת סאב-אייטם מעבירה את הטריגר אוטומטית לגרסת הסאב-אייטם שלו.

## שלב 2: תנאים (לא חובה)

תנאים מצמצמים את האוטומציה למקרים מסוימים — למשל "ורק אם **עדיפות** היא **גבוהה**".

1. לחצו על **+ תנאי** בשורה **ורק אם**.
2. בחרו עמודה, אופרטור (כמו "הוא", "אינו", "ריק") וערך.
3. להוספת תנאי נוסף, בחרו אם הוא מתחבר ב**וגם** או ב**או**. אפשר גם ליצור קבוצת תנאים מקוננת, ולשלול תנאי.

מתחת לתנאים מופיע משפט קריא שמסכם אותם, עם סוגריים סביב כל קבוצה, כדי שתוכלו לוודא שהלוגיקה נכונה.

## שלב 3: פעולות

לחצו על **+ בחירת פעולה** (ובהמשך **+ פעולה**) ובחרו מה יקרה. אפשר להוסיף כמה פעולות; הן רצות לפי הסדר, וכל פעולה נמחקת בלחיצה על סמל הפח שלה.

| קבוצה | פעולה | איך היא נקראת במשפט |
| --- | --- | --- |
| עמודות | שינוי סטטוס | שנה את {עמודה} ל{תווית} |
| עמודות | קביעת ערך בעמודה | קבע את {עמודה} ל{ערך} |
| עמודות | קביעת תאריך | קבע את {עמודה} ל{היום / עכשיו / ריק, ועוד N ימים} |
| עמודות | שינוי שם הפריט | שנה את שם הפריט ל{שם} |
| עמודות | הוספה למספר | הוסף {1} ל{עמודה} |
| עמודות | ניקוי עמודה | נקה את {עמודה} |
| עמודות | הפעלת / עצירת מעקב זמן | הפעל מעקב זמן ב{עמודה} (ובחירה של מי הטיימר) |
| עמודות | יצירת תמונה עם AI | ליצור תמונה בעמודה {עמודת קבצים}: {תיאור} |
| פריטים | העברה לקבוצה | הזז לקבוצה {קבוצה} |
| פריטים | שכפול הפריט / העברה לארכיון / מחיקת הפריט | שכפל את הפריט, העבר לארכיון, מחק את הפריט |
| סאב-אייטמים ופריט האב | יצירת סאב-אייטם | צור סאב-אייטם {שם} |
| סאב-אייטמים ופריט האב | קביעת עמודה בפריט האב / בכל סאב-אייטם | קבע את {עמודה} של פריט האב ל{ערך} |
| סאב-אייטמים ופריט האב | העתקה מפריט האב / לפריט האב / לכל סאב-אייטם | העתק את {עמודה} של פריט האב אל {עמודה} |
| אנשים | שיבוץ / הסרת שיבוץ | שבץ את {מישהו} ב{עמודה} |
| התראות ותקשורת | התראה | שלח התראה ל{מישהו}: {הודעה} |
| התראות ותקשורת | שליחת מייל | שלח מייל ל{מישהו}: {נושא} |
| התראות ותקשורת | כתיבת עדכון | כתוב עדכון: {תוכן} |
| התראות ותקשורת | שליחת SMS | שלח SMS ל{עמודת טלפון}: {הודעה} |
| חוצה לוחות | העברה ללוח / יצירת פריט | הזז ללוח {לוח}, צור פריט בלוח {לוח} |
| חוצה לוחות | קישור פריטים | קשר פריטים ב{עמודת חיבור} |
| חוצה לוחות | העתקה מפריט מקושר | קבע את {עמודה} ל{עמודה} של הפריט המקושר ב{עמודת חיבור} |
| Webhooks ואינטגרציות | Webhook | שלח webhook ל{כתובת} |
| Webhooks ואינטגרציות | הפעלת סוכן | הפעל את הסוכן {סוכן}: {הנחיה} |
| Webhooks ואינטגרציות | שליחה לאינטגרציות (n8n / Make) | שלח את האייטם לאינטגרציות בערוץ {ערוץ} |

![תפריט הפעולות של בונה האוטומציות, מחולק לקבוצות](images/automation-builder-2.webp)

> **שימו לב:** חלק מהפעולות (Webhook, מייל, SMS, שליחה לאינטגרציות, הפעלת סוכן ויצירת תמונה) תלויות בחבילה של החשבון. אם הן לא כלולות, הן מופיעות בתפריט כמושבתות, עם הסבר וקישור לשדרוג.

### למי נשלחת התראה

בפעולות התראה, מייל ושיבוץ אפשר לבחור: **יוצר הפריט**, **מי שביצע את השינוי**, **בעלי הלוח**, **מנויי הלוח**, עמודת אנשים מהפריט (או מפריט האב), או אדם מסוים מהחשבון. במייל אפשר לבחור גם עמודת אימייל.

### משתנים בטקסט

בכל שדה טקסט (הודעה, נושא, שם, תוכן עדכון) מופיעים מתחת לתיבה כפתורי משתנים: **שם הפריט**, כל עמודה של הפריט, **שם הלוח**, **קישור לפריט**, **מי שביצע** ו**היום**. לחיצה מוסיפה את המשתנה, והוא מוצג כצ'יפ קריא — למשל "הפריט {שם הפריט} עבר לשלב {סטטוס}".

### מיפוי עמודות בין לוחות

בפעולות **יצירת פריט** ו**העברה ללוח** מופיע כפתור **מיפוי עמודות (N)**. בו תקבעו מה עובר ללוח היעד: לחצו **מיפוי לפי שם** כדי להתאים אוטומטית עמודות עם אותו שם, או בחרו לכל עמודה ביעד את עמודת המקור. ביצירת פריט אפשר גם לקבוע **ערך קבוע**. עמודה שלא ממופה נשארת ריקה.

## שלב 4: שם ושמירה

1. בשדה **שם (לא חובה)** אפשר לתת לאוטומציה שם. אם תשאירו אותו ריק, השם יהיה תיאור הטריגר והפעולות.
2. לחצו **שמירה והפעלה** כדי שהאוטומציה תתחיל לרוץ מיד, או **שמירה ככבויה** כדי להפעיל אותה מאוחר יותר.

אם משהו לא תקין — עמודה שנמחקה, תווית שלא קיימת, פעולה שצריכה פריט כשהטריגר לא מספק אחד — יופיע הסבר מתחת לבונה, והצ'יפ הבעייתי יסומן.

## שאלות נפוצות

**אפשר לבנות אוטומציה על סאב-אייטמים?**\
כן. בחרו טריגר מקבוצת **סאב-אייטמים**, או בחרו בעמודה של סאב-אייטם בתוך טריגר רגיל. בבורד עם כמה רמות אפשר לבחור **בכל רמה**, **סאב-אייטמים בלבד** או **סאב-סאב-אייטמים בלבד**.

**מה קורה אם פעולה אחת נכשלת?**\
הפעולות האחרות ממשיכות לרוץ. ההיסטוריה של האוטומציה תראה בדיוק איזו פעולה נכשלה ולמה.

**למה אני לא רואה את הטריגר של זרימות חיצוניות?**\
רק מי שיש לו גישה למסך הזרימות יכול לבחור חיבור. בקשו ממנהל החשבון לשתף אתכם בזרימות.

## ראו גם

- סאב-אייטמים ורמות עומק
