MCP הוא תקן פתוח שמאפשר לעוזרי AI — Claude.ai, ChatGPT, Claude Code, Cursor ו-VS Code — לעבוד ישירות עם הבורדים שלכם: לחפש פריטים, לסכם עדכונים, ליצור משימות ולעדכן סטטוסים, הכול מתוך שיחה רגילה עם העוזר. העוזר פועל תמיד בשמכם ובהרשאות שלכם בלבד — הוא לא רואה ולא משנה שום דבר שאתם לא יכולים לראות או לשנות בעצמכם.

## מה תלמדו

- מה צריך לפני שמתחברים
- איך מחברים את Claude.ai ו-ChatGPT, ומה מאשרים במסך החיבור
- איך מחברים כלי פיתוח כמו Claude Code, Cursor ו-VS Code
- איך רואים ומנתקים אפליקציות מחוברות
- מה מנהל החשבון קובע

## לפני שמתחילים

- **כתובת ה-MCP:** כתובת אחת לכל החשבונות, שמנהל החשבון מוצא ב**ניהול החשבון** ← **AI ו-MCP**, באזור **שרת MCP**, עם כפתור **העתקה**. בקשו אותה ממנו.
- **הרשאה:** מנהל החשבון קובע **מי יכול לחבר כלי AI** — **רק מנהלים**, **חברי צוות**, או **חברי צוות וצופים**. אורחים לעולם אינם יכולים לחבר.
- **חבילה:** חיבור אפליקציות AI תלוי בחבילה של החשבון.

## חיבור Claude.ai או ChatGPT

שני אלה מתחברים בהתחברות מאובטחת (OAuth): מדביקים רק את כתובת ה-MCP, בלי טוקן, ומאשרים במסך שלנו.

**ב-Claude.ai:**

1. הגדרות ← Connectors ← Add custom connector.
2. שם: Bines OS. כתובת: כתובת ה-MCP. לשאר השדות אין צורך.
3. לחצו Connect — ייפתח מסך האישור שלנו.

**ב-ChatGPT:**

1. הגדרות ← Apps & Connectors ← Advanced ← הפעילו Developer mode.
2. Create ← שם: Bines OS, כתובת: כתובת ה-MCP, אימות: OAuth.
3. לחצו Connect — ייפתח מסך האישור שלנו.

### מסך האישור

אם אינכם מחוברים למערכת, תתבקשו להיכנס. לאחר מכן יופיע המסך **\<שם האפליקציה\> מבקשת גישה**, עם שם האפליקציה והכתובת שאליה תחזרו.

1. תחת **לאיזה חשבון לחבר?** בחרו חשבון. כל חיבור הוא לחשבון אחד; לחשבון נוסף מתחברים שוב. חשבון שבו אינכם מורשים יופיע מושבת, עם הסבר.
2. תחת **מה מותר לה**:

   - **קריאה** — תמיד כלולה: לוחות, פריטים, עדכונים, אנשים, אוטומציות וחיפוש — מה שאתם רואים.
   - **עריכה** — יצירה ושינוי של פריטים, עדכונים, קבוצות, עמודות ולוחות. מחיקה עוברת לסל.
   - **אוטומציות** — יצירה, הפעלה וכיבוי של אוטומציות.
3. תחת **באילו לוחות** בחרו **כל הלוחות שלי** (כולל לוחות שיתווספו בהמשך) או **רק לוחות שאבחר**, וסמנו לפחות לוח אחד.
4. לחצו **אישור וחיבור**. תחזרו לאפליקציה, והחיבור מוכן. **ביטול** מחזיר אתכם בלי לחבר.

![מסך האישור לחיבור אפליקציית AI עם בחירת חשבון, הרשאות ולוחות](images/mcp-connect-1.webp)

> **שימו לב:** אם מופיעה ההערה שהשם נמסר על ידי האפליקציה ולא אומת — אשרו רק אם אתם אלה שהתחלתם את החיבור הרגע.

> **טיפ:** בחשבון שבו אתם צופים, החיבור יהיה לקריאה בלבד.

## חיבור Claude Code, Cursor או VS Code

כלים אלה מתחברים עם טוקן API אישי במקום OAuth:

1. צרו טוקן אישי (**הפרופיל שלי** ← **טוקני API** ← **טוקן חדש**). ההרשאות והלוחות של הטוקן הם בדיוק מה שהכלי יקבל — למשל, טוקן לקריאה בלבד ייתן גישת קריאה בלבד.
2. הוסיפו את השרת בכלי, עם כתובת ה-MCP והכותרת `Authorization: Bearer <TOKEN>`:

   - **Claude Code:** פקודת `claude mcp add --transport http` בטרמינל.
   - **Cursor:** בקובץ `~/.cursor/mcp.json`.
   - **VS Code:** בקובץ `.vscode/mcp.json`.

מנהל החשבון רואה במסך **AI ו-MCP**, באזור **איך מתחברים**, קטע הגדרה מוכן להעתקה לכל כלי — בקשו ממנו לשלוח לכם אותו.

## מה העוזר יכול לעשות

העוזר מקבל כלים כמו חיפוש פריטים, קריאת לוח, יצירה ועדכון של פריטים, כתיבת עדכונים ועבודה עם אוטומציות — לפי ההרשאות שאישרתם. כל שינוי שהוא מבצע נרשם ביומן הפעילות עם הסימון "דרך \<שם האפליקציה\>", וניתן לבטל אותו כמו כל שינוי אחר.

## אפליקציות מחוברות וניתוק

1. פתחו **הפרופיל שלי** ← לשונית **טוקני API**.
2. באזור **אפליקציות AI מחוברות** מופיעה כל אפליקציה שחיברתם: מתי **חוברה**, **שימוש אחרון**, ולאילו לוחות יש לה גישה.
3. לחצו **ניתוק** ואשרו. האפליקציה מאבדת את הגישה מיד, ואפשר לחבר אותה שוב בכל זמן.

![אזור אפליקציות AI מחוברות בלשונית טוקני API של הפרופיל](images/mcp-connect-2.webp)

מנהלי החשבון רואים את האפליקציות של כל החברים ב**ניהול החשבון** ← **AI ו-MCP**, ויכולים לנתק כל אחת מהן.

## מה מנהל החשבון קובע

במסך **AI ו-MCP**, באזור **שרת MCP**:

- **MCP פעיל בחשבון** — כבוי, אף כלי AI לא יכול להתחבר.
- **מי יכול לחבר כלי AI** — מנהלים תמיד; אורחים אף פעם.
- **פעולות רגישות (מחיקה)** — **מותר** או **חסום**. כשחסום, כלי מחיקה לא יוצגו לעוזרים בכלל.
- **הכלים שתקבלו** — רשימת הכלים שהשרת מציע.

## שאלות נפוצות

**במסך האישור כתוב "בחשבון הזה רק מנהלים יכולים לחבר אפליקציות AI".**\
המנהל הגביל את החיבור למנהלים. פנו אליו אם אתם צריכים גישה.

**מה ההבדל בין זה לבין שרתי MCP חיצוניים?**\
כאן עוזרים חיצוניים מתחברים **אלינו**. שרתי MCP חיצוניים הם הכיוון ההפוך: כלים של שרתים אחרים שהסוכנים והאוטומציות שלנו משתמשים בהם — ראו "הגדרת AI לחשבון".
