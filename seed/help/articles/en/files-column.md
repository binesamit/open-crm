A **Files** column keeps everything related to an item in one place: contracts, quotes, photos, screenshots and internal docs. Instead of hunting for files in email or shared folders, the whole team sees them right in the item's row, and can open a preview, download them and leave a comment on the file itself.

## What you'll learn

- How to upload files to a cell, including dragging and pasting a screenshot
- How to create a new doc right in the cell
- How to work with the file viewer: preview, download and comments
- How to remove a file or doc from the cell

## Add a Files column

Click **+** (**Add column**) at the end of the header row and choose **Files**. You can add several Files columns, for example "Contract" and "Photos".

## Upload files

There are three ways to add a file to a cell:

1. **From your computer:** Click the cell, then **Upload a file**, and choose one or more files.
2. **Drag:** Drag files from your computer and drop them on the cell.
3. **Paste:** Copy an image or file (a screenshot, for example), select the cell and press Ctrl+V (or ⌘+V on a Mac). A pasted screenshot gets a name automatically.

While uploading, the cell shows a loading indicator. When it's done, the files appear in the cell and in the item card.

![An open Files cell with attached files and the Upload a file and New doc buttons](images/files-column-1.webp)

> **Note:** You can upload files of up to 500MB each. The account's total storage depends on the plan. If you don't have edit permission on the column, you'll see the message **You don't have permission to add files to this column**.

## A new doc inside the cell

Besides files from your computer, you can create a rich doc right in the cell:

1. Click the cell, then **New doc**.
2. The doc opens in a side panel. Write in it like any doc in the platform: headings, lists, tables and images.
3. The doc appears in the cell as a chip, and clicking it opens it again.

The doc gets the item's permissions: anyone who can see the item can also see the doc. To remove a doc from the cell, click its **Remove the doc** button. The doc goes to the Trash and you can restore it from there.

## The file viewer

Clicking a file's name opens the file viewer:

- **Preview** of images, PDF files and more. For images you can use **Zoom in** and **Fit to window**.
- **Office documents** (Word, Excel, PowerPoint) are shown through **Preview with Office Online**. Note that in this case the link to the file is sent to Microsoft to display it.
- **Previous file** / **Next file** – move between all the files in the cell. The top of the viewer shows your position, for example "2 of 5".
- **Download** – save the file to your computer.
- **Remove file** – after you confirm. You can also remove a file from the cell's panel by clicking the ✕ next to it.
- **Comments on the file** – type in the **Write a comment on the file…** field and click **Send**. The comment is saved as an update on the item with a reference to the file, so the whole discussion stays in one place.

![The file viewer with an image preview, navigation between files and comments](images/files-column-2.webp)

For file types without a preview you'll see the message **There is no preview for this file type**, and you can still download them.

## Where else you see the files

- **Item card** – the fields tab shows the same Files cell, with the same options.
- **Files view** – a special board view that gathers the files from all items in one place.

## Frequently asked questions

**What's the difference between removing a file and removing a doc from the cell?**\
A doc created in the cell goes to the Trash and can be restored from there, back to the same cell. A file uploaded from your computer is detached from the cell, so before removing an important file, make sure you have a copy of it.

**Are files copied when I duplicate an item?**\
Files are stored in the column through the upload mechanism, so the column's content isn't copied automatically when you duplicate an item or board.

**Can I convert a Files column to another type?**\
No. Files columns don't support type conversion. If you need to, add a new column of the type you want.
