These two views present the board visually. The **Files view** gathers all the board's files in one place, from the file columns and from updates, so you don't have to hunt for a contract or a photo item by item. The **Cards view** shows each item as a card in a gallery, with the fields you chose, and suits anyone who likes to scan information at a glance.

## What you'll learn

- How to create a Files view and filter it by column, file type and uploader
- How to open and download each file, and find the item it belongs to
- How to create a Cards view and choose the fields on the card

## Files view

### Creating the view

1. At the top of the board, click **+** next to the view tabs.
2. Choose **Files**, give it a name and click **OK**.
3. All the board's files appear as tiles, including subitem files.

![A Files view with a filter bar at the top and file tiles: image thumbnails and documents](images/files-cards-views-1.webp)

### What appears on each tile

- A thumbnail for images, or an icon by file type (PDF, document, spreadsheet, presentation, video and more).
- The file name and a **Download** button.
- The name of the item the file belongs to; clicking it opens the item card.
- Who uploaded the file and when, and whether it was attached **In an update**.

Clicking the tile opens the file viewer: a preview, moving to the previous or next file, comments and download.

### Filtering and sorting

In the bar at the top of the view:

| Filter | Options |
| --- | --- |
| **File column** | **All columns**, or a specific file column |
| **File type** | **All types**, **Images**, **PDF**, **Video**, **Audio**, **Docs**, **Spreadsheets**, **Presentations**, **Other** |
| **Uploaded by** | **Everyone**, or a specific person |
| **Sort** | **Newest first**, **Oldest first**, **By name**, **Largest first** |

The **Include files from updates** checkbox sets whether to also show files attached to updates and replies, or only files from columns. The number of files appears at the side, for example **24 files**.

> **Tip:** The board's search and **Filter** apply here too: only files of items that match the filter are shown. This way you can, for example, see only the contracts of clients with the status "Signed".

> **Note:** Everyone sees only files of items and columns they're allowed to see. If the board has a viewing restriction, the view respects it.

The choices in the filter bar are saved as part of the view (after **Save to view**), so you can create, for example, a permanent view called "Photos from the field".

## Cards view

### Creating the view

1. Click **+** next to the view tabs and choose **Cards**.
2. Give it a name and click **OK**.
3. The items that match the filter are shown as a gallery of cards.

![A Cards view with a gallery of items, each card showing name, status, owner and date](images/files-cards-views-2.webp)

### What you can do with a card

- Clicking a card opens the item card.
- Right-clicking (or **⋯**) opens the item menu, as in the table.
- The updates counter shows how many updates the item has.

### Choosing the fields on the card

1. In the toolbar, click **View settings**.
2. Under **Fields on cards**, check the columns that appear on each card.
3. Click **Save to view** so the choice applies to everyone.

When you don't choose fields, the card shows up to four useful fields: status, people, number and date. Empty fields aren't shown.

> **Tip:** On a phone, you can also show the main table as cards: in a table's **View settings**, under **Table on phones**, choose **Cards**.

## Frequently asked questions

**A file I uploaded doesn't appear in the Files view.**\
Check that the filters are set to **All columns** and **All types**, that no board filter is hiding the item, and if the file was attached to an update, that **Include files from updates** is checked.

**Can I upload files from the Files view?**\
You upload files in the file column or in an update on the item; they appear in the view right away.

**What's the difference between the Cards view and Kanban?**\
In Kanban, the cards are split into columns by status and you can drag between them. In the Cards view, all the items are shown together in one gallery.
