If you work in the system all day, you know how much time you save when your hands stay on the keyboard. Bines OS supports a range of keyboard shortcuts: for undoing an action done by mistake, for quick search, for moving between cells in a table as in a spreadsheet, and for working with menus without a mouse. In this article you'll find the full list, organized by the context each shortcut works in.

## What you'll learn

- How to open the shortcut list from inside the system
- General shortcuts that work everywhere
- Shortcuts for working on a board and in a table
- Shortcuts for working with menus

## Opening the shortcut list

On any screen, press **Shift+?** (when the cursor isn't inside a text field). The **Keyboard shortcuts** window opens with all the shortcuts, split into three parts: **Everywhere**, **On a board** and **Menus**. Close it with Esc.

![The keyboard shortcuts window with its three parts: Everywhere, On a board and Menus](images/keyboard-shortcuts-1.webp)

> **Tip:** On a Mac, use ⌘ (Cmd) wherever it says Ctrl. Letter shortcuts work with any keyboard layout, even when the keyboard is set to Hebrew.

## General shortcuts

| Shortcut | Action |
| --- | --- |
| Shift+? | **Shortcut list** |
| Ctrl+Z | **Undo the last action (within a minute)** |
| Ctrl+Shift+Z (or Ctrl+Y) | **Redo what was undone** |
| Ctrl+B | **Search everything** |
| Esc | **Close dialog / menu** |

> **Note:** Undo with Ctrl+Z is available for the last action you took, for one minute from when you took it. To restore older things, use the board's activity log, the Trash or the archive.

## Shortcuts on a board

### General on a board

| Shortcut | Action |
| --- | --- |
| Ctrl+F | **Search the board** |
| Ctrl+G | **Collapse / expand all groups** |
| Ctrl+Shift+L | **The board's activity log** |

### Selecting items

| Shortcut | Action |
| --- | --- |
| Ctrl+A | **Select every item in the view** |
| Shift+click | **Select a range (on the checkbox)**: click one item's checkbox, then Shift+click another |
| Delete | **Delete the selected items** |
| Esc | **Clear the selection** |

### Moving and editing in a table

The table behaves like a spreadsheet: click one cell, and from there you can work from the keyboard.

| Shortcut | Action |
| --- | --- |
| Arrows ↑ ↓ ← → | **Move between cells** |
| Tab / Shift+Tab | **Next / previous cell** |
| Enter | **Edit the cell** |
| Shift+arrows | **Select a range of cells** |
| Ctrl+C / X / V | **Copy / cut / paste cells** |
| Delete | **Clear the cell (or range)** |

> **Tip:** You can copy a range of cells from the system and paste it into Excel, and the other way around: copy data from a spreadsheet and paste it straight into the table.

## Shortcuts in menus

| Shortcut | Action |
| --- | --- |
| Shift+F10 | **Actions menu of what has focus**, like a right-click |
| ↑ ↓ | **Move between menu items** |
| Enter | **Choose a menu item** |
| Esc | Close the menu |

That way you can, for example, Tab to a row in the sidebar, press Shift+F10 to open its menu, choose an action with the arrows and confirm with Enter, without touching the mouse.

## Frequently asked questions

**I pressed Shift+? and nothing happened.**\
The cursor may be inside a text field, in which case the key just types the character. Click outside the field (or press Esc) and try again.

**Ctrl+F opens the browser's search, not the board's.**\
The shortcut works only when a board is open on the screen. On other screens the browser handles it as usual.

**Can I set my own shortcuts?**\
Not at the moment. The list in the **Keyboard shortcuts** window is the full list of available shortcuts.
